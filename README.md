# OpenSeesPy Structural Analysis Examples and GPT-4 Integration

This repository contains example scripts, utilities, and tools for conducting structural analysis using OpenSeesPy and GPT-4. The scripts are organized into examples, a main GPT-based workflow, and auxiliary files for configuration and processing.

## Files Overview

### Example Files
- **`Example 1.py`**  
  OpenSeesPy code for a one-story frame.

- **`Example 2.py`**  
  OpenSeesPy code for a two-story frame.

- **`openseespy test.py`**  
  The prototype one-story frame example from the OPSVis website.

### GPT Integration Workflow
- **`gpt_test.py`**  
  Main program to use the GPT-4 API. Reads user requests and performs structural analysis through OpenSeesPy and the OPSVis Python package.

### Modular Workflow Files
- **`A.py`**  
  Parameters configuration script for structural analysis.

- **`B.py`**  
  Input file generated by GPT-4 based on the user's request.

- **`C.py`**  
  Post-processing script to analyze results from OpenSeesPy.

- **`D.py`**  
  Complete code that combines `A.py`, `B.py`, and `C.py` in sequence to execute structural analysis tasks.

### Supporting Files
- **`background.txt`**  
  Background information to help GPT-4 better understand the context and tasks.

- **`request.txt`**  
  User input requests for GPT-4 to process.

## Usage Instructions

1. **Run Example Scripts**  
   Test the example scripts (`Example 1.py` and `Example 2.py`) to understand the basic setup and workflow for structural analysis using OpenSeesPy.

2. **Use GPT-4 Integration**  
   - Provide a description of your task in `request.txt`.
   - Run `gpt_test.py` to generate the required input file (`B.py`) and execute the structural analysis.

3. **Run Modular Scripts**  
   - Configure parameters in `A.py`.
   - Ensure `B.py` is generated by GPT-4 or manually updated for your structure.
   - Execute `C.py` for post-processing or `D.py` to run the full workflow in sequence.

## Dependencies
- Python 3.12+
- [OpenSeesPy](https://openseespydoc.readthedocs.io/en/latest/)
- [OPSVis](https://openseespydoc.readthedocs.io/en/latest/OPSVis.html)
- GPT-4 API access
